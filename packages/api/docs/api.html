Resttek API (1.0.0)

Download OpenAPI specification:

API REST de Resttek, plataforma de gestión de restaurantes.

  • Prefijo de todos los recursos: /api/v1. El healthcheck /health cuelga de la raíz.
  • Autenticación: JWT (8 h) obtenido en /auth/login o /auth/register, enviado como Authorization: Bearer <token>.
  • Roles: admin, manager, camarero, cocinero, cliente.
  • Los clientes son filas de employees con role = cliente y restaurantId = null; comparten los endpoints de auth.
  • Cada unidad pedida en un pedido se convierte en su propio OrderItem con quantity: 1.
  • Los errores de dominio (AppError) responden { error, message }; los endpoints de pedidos y los middlewares de auth responden solo { error }.
